# 汽车之家 经销商入驻与结算规范

版本：v3.4　生效日期：2026-10-01

## 1. 适用范围

适用于通过线索平台接入的二手车与新车经销商，含区域代理与单店两类主体。

## 2. 汽车之家 入驻资质清单

1. 营业执照扫描件（需与注册地址一致）
2. 法人身份证正反面
3. 结算账户开户许可或银行开户证明
4. 门店实景照片不少于 3 张
